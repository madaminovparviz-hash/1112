# Project Worklog — SDA Church Website (RU/TJ) + Admin Panel

Project: Next.js 16 (App Router), TypeScript, Tailwind 4, shadcn/ui.
Single user-visible route `src/app/page.tsx` renders the whole SPA (public site + admin panel) with hash-based internal navigation (`#/`, `#/about`, ..., `#/admin`).
Data layer: client-side demo persistence via localStorage (Zustand persist). DO NOT introduce additional routes; DO NOT use z-ai-web-dev-sdk on the client.
